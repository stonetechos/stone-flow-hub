## 🌐 Instant Deployment to `www.vedoravision.in`

### Option 1: Cloudflare Pages (Recommended)

1. Push this folder to your GitHub repository or deploy directly via Wrangler:
   ```bash
   npx wrangler pages deploy ./vedora-vision-website --project-name=vedora-vision
   ```
2. In Cloudflare Dashboard $\rightarrow$ Pages $\rightarrow$ Custom Domains, attach `www.vedoravision.in` and `vedoravision.in`.

### Option 2: Vercel / Netlify

1. Drag and drop the `vedora-vision-website` folder into Vercel/Netlify.
2. Under Domain Management, map `www.vedoravision.in` with CNAME record.
