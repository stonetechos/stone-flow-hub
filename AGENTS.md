## 1. Product & Architecture Overview

**Stone Tech OS (STOS)** is an enterprise ERP and operational hub for stone fabrication and construction operations.

- **Frontend & Routing:** React 19, TanStack Start v1 (file-based routing under `src/routes/`), TanStack Query v5.
  - **CRITICAL:** Never hand-edit `src/routeTree.gen.ts` — it is automatically generated by TanStack Router.
- **UI & Design:** Tailwind CSS v4 (`src/styles.css`), shadcn/ui components (`src/components/ui/`), Lucide icons.
- **Backend & Database:** Supabase (PostgreSQL 15, ~126 tables with RLS on all tables, auth roles via `has_role(uuid, app_role)`).
- **Server Functions:** `createServerFn` with `requireSupabaseAuth` middleware for authenticated DB operations.
- **Mobile (Android):** Capacitor 8 (`@capacitor/android`), package ID `in.vedoravision.stonetechos.app`, configured in `capacitor.config.ts`. Android native workspace in `android/`.

## 2. Business Flow & Domain Lifecycles

```text
Customer → Enquiry → Project · Estimate → Quote → Sales Order → (RFQ / PO / Manufacturing) → Dispatch → Installation → Invoice → Receipt → Ledger
```

- **Lineage:** Inventory movements bridge PO → Manufacturing → Dispatch via `inventory_movements`.
- **Cross-cutting panels:** Tasks, Comments, Attachments, Notifications, Timeline, and Activity Log exist on every major entity.

---

## 3. Frontend & Component Conventions

Always adhere to the established design system:

1. **List Pages:** Use `<DataToolbar>` + `<DataTableShell>` + `<TablePagination>` + `useTablePrefs`.
2. **Create / Edit Pages:** Use `<FormLayout>` + `<FormSection>` + `<FormGrid>` + sticky `<FormActions>`.
3. **Entity Selection:** Always use `<EntityPicker>` (`src/components/forms/EntityPicker.tsx`) for dropdowns/foreign keys.
4. **Destructive Actions:** Always wrap in `<ConfirmDialog>` or `<SafeDeleteDialog>`.
5. **Cache Invalidation:** Always invalidate React Query caches using the helpers in `src/lib/query-invalidation.ts`.
6. **Routes with Loaders:** Always specify `errorComponent` and `notFoundComponent`.

---

## 4. Mobile / Android Conventions

- To compile the mobile client: `npm run build:capacitor` (outputs a dedicated static SPA shell to `dist-capacitor/client`).
- To sync native assets: `npm run cap:sync` (`npx cap sync android`).
- The mobile app runs edge-to-edge; keep safe-area insets (`env(safe-area-inset-*)`) and dynamic status bar styling intact.

## 5. Verification & Quality Gates

Before finishing any task or commit, verify the codebase with:

- **Unit Tests:** `bun test` (all tests located in `src/`).
- **Type Checking:** `npm run typecheck` (`tsc --noEmit`).
- **Linting:** `npm run lint` (`eslint .`).
- **Formatting:** `npm run format` (`prettier --write .`).
